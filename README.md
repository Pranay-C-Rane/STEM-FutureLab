\# STEM FutureLab



STEM FutureLab is an interactive web-based STEM learning platform designed for school students.



\## Features



\- 🤖 Virtual Robot Lab

\- 🧠 Smart Learning

\- 🧩 Logic Challenge

\- 💻 Coding Playground

\- 👁️ AI Vision Lab

\- ⚡ Smart Circuit Lab

\- 📊 My Progress

\- 📝 Student Feedback

\- 📈 Reviews Dashboard



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- Chart.js

\- GitHub Pages



\## Project Purpose



The project aims to promote STEM learning through interactive activities involving coding, computational thinking, logic, robotics, AI, and problem-solving.
